Jumptoon Support

Need help with Jumptoon? We're here to help.

If you have a question, encounter a bug, or need assistance with Jumptoon, please contact the developer using the email below.

Contact Support

Email: aldoxhako@outlook.com

When contacting support, please include as much information as possible, such as:

  • Your device model and operating system version
  • The version of Jumptoon you are using
  • A description of the issue you encountered
  • Steps to reproduce the issue, if applicable
  • Screenshots or screen recordings, if helpful

Leaderboard Issues

If you are experiencing an issue with the online leaderboard, please include your leaderboard display name and, if possible, the approximate date and time when the issue occurred.
